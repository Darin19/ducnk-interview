In AI Hub, the core idea was to build an internal AI asset lifecycle management platform for managing and governing datasets and models in a secure, reusable, and traceable way. The most important module was Dataset Management, where each dataset had a standardized Dataset Card containing metadata such as owner, sponsor, department, data type, schema, sensitivity level, usage scope, version, labels, and related models. We also supported dataset templates so different dataset types, such as tabular, image, text, or log data, could follow consistent registration standards. Another key module was Data Source Management, which controlled where the dataset came from, such as internal databases, APIs, file storage, data warehouses, external vendors, or purchased data packages. Sensitive actions like uploading new source files, changing source connections, downloading raw data, or deleting source data could be routed through approval. The platform also had a flexible Approval Workflow Management module for asset purchase requests, dataset/model registration, sharing, edit/delete requests, data source approval, training job approval, and model deployment approval. The workflow supported multi-level approval, parallel approval, conditional routing, automatic approver assignment, comments, rejection, change requests, SLA tracking, and notifications. In addition, AI Hub managed Dataset and Model Lifecycle Status, such as Draft, Under Review, Approved, Published, In Use, Deprecated, Archived, Staging, and Production. These statuses controlled what users could do at each stage. Finally, the system implemented Permission and Access Control with both function-level and data-level permissions, based on roles, departments, ownership, sensitivity level, asset status, and usage scope. Besides these core modules, AI Hub also included Model Registry, Dataset Catalog and Search, Training Job Management, Evaluation and Benchmarking, Notification Templates, Audit Trail, and Dashboard Reporting.
